# Changelog

## 0.4.0

- Explicit registry trust, signed root rotation, rollback protection and cache
  reverification; unsigned development restores require `--allow-unsigned`.
- Authenticated, bounded, immutable package publication over HTTPS.
- Corrections for array null safety, optional/struct/result equality, catch
  bindings, JSON conversions, closed databases and handle lifecycle.
- LSP input validation and bounded frames; GraphQL string and JSON correctness.
- HTTP package ranges now match file registry resolution.

## 0.3.1

- ABI v2 ownership, task handles, Text/Decimal imports and C11 headers.
- SQLite/PostgreSQL adapters, capturing callbacks, package restore and gallery
  publication, and language-server foundations.

## 0.3.0

- Avalonia GUI expansion (layouts, menus, rich controls, typed callbacks)
- REST (`vela.core.http`), GraphQL (`vela.core.graphql`), gRPC (`vela.core.grpc`)
- Adapter staging for HTTP/gRPC runtimes
- Mintlify documentation site

## 0.2.0

- Desktop GUI foundation

## 0.1.0

- Initial public compiler release

See the root [`CHANGELOG.md`](https://github.com/stescobedo92/VelaMiniCompiler/blob/master/CHANGELOG.md) for the full list.
